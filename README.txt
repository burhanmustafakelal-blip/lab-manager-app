نظام إدارة المعمل - نسخة أولية قابلة للتثبيت كتطبيق ويب تقدمي (PWA)

الموجود حاليًا:
- ملخص مالي بالمعادلات المطابقة للملف الأصلي.
- إيرادات الفحوصات: الإجمالي = العدد × السعر، والآجل = الإجمالي - المحصل.
- المستهلكات: رصيد آخر المدة = أول المدة + الوارد - المستخدم - التالف، وتكلفة المستخدم/التالف.
- مشتريات المعمل: الإجمالي = الكمية × سعر الوحدة، والمتبقي للمورد = الإجمالي - المدفوع.
- المصروفات التشغيلية.
- حفظ محلي على الجهاز، والعمل دون اتصال بعد أول تحميل وتثبيت، ونسخ احتياطي JSON واستيراد، وتصدير CSV.

مهم:
- هذه النسخة لا تحتوي على مزامنة سحابية مفعلة. المزامنة التلقائية بين أكثر من جهاز تتطلب استضافة HTTPS وخادم مزامنة وقواعد لحل تعارض التعديلات. حقل رابط المزامنة لا يفعّلها وحده.
- لتثبيت PWA على Android، ارفع الملفات إلى استضافة HTTPS ثم افتح الرابط في Chrome واختر القائمة > إضافة إلى الشاشة الرئيسية / تثبيت التطبيق. لا يمكن تثبيت الخدمة العاملة دون اتصال بصورة موثوقة من فتح ملف HTML محلي فقط.
- احفظ نسخة احتياطية دوريًا. البيانات محفوظة في مساحة المتصفح على الجهاز؛ حذف بيانات المتصفح قد يحذفها.
- العملة جنيه سوداني، ويمكن تعديل الواجهة لاحقًا.
